# Промт: собрать такую же панель под свой дом с помощью LLM

Открой сессию с LLM, у которой есть доступ к файлам и терминалу (Claude Code,
Claude с инструментами, Cursor, Codex и т.п.). Лучше всего — если у неё ещё
подключён Home Assistant (через MCP-сервер для Home Assistant — встроенную интеграцию
«Model Context Protocol Server» или сторонний, например `ha-mcp`): тогда она сама
найдёт твои сущности и проверит автоматизации. Без доступа к HA тоже можно —
она попросит прислать список сущностей.

Скопируй сообщение ниже целиком, подставив ссылку на этот репозиторий.

---

```text
Привет! Хочу собрать прошивку для сенсорной панели Home Assistant по этому
проекту: https://github.com/peholod009/esphome-4848s040-ha-panel

Что это: ESPHome + LVGL прошивка для Guition ESP32-S3-4848S040 (480×480,
ST7701S + GT911), 5 экранов (главная, свет в комнате, свет во дворе, музыка,
настройки), собирается генератором tools/gen_panel.py поверх библиотеки
https://github.com/agillis/esphome-modular-lvgl-buttons.

Порядок работы:

1. Склонируй репозиторий и прочитай README.md, home-assistant/README.md,
   tools/README.md, design/README.md (+ макеты design/*.html) и шапку tools/gen_panel.py (там правила переноса макета
   в LVGL). Не начинай менять файлы, пока не прочитал.

2. Задай мне вопросы — коротко, списком, одним сообщением:
   - какая у меня панель (если не 4848S040 — что за экран, разрешение,
     есть ли в библиотеке файл hardware/ для неё);
   - какие экраны нужны и какие убрать (например, нет бани — убрать плашки
     парной/бани/туалета и показать что-то другое);
   - какой свет / выключатели на каждом экране и как они должны называться;
   - какой плеер Music Assistant и какие станции/плейлисты на кнопки
     (или кнопки музыки не нужны);
   - датчики для главной: погода, температура, что-то ещё;
   - нужно ли гашение экрана по движению и какими датчиками;
   - язык интерфейса и поворот экрана.

3. Найди мои сущности. Если у тебя есть доступ к Home Assistant — найди их
   сам и покажи таблицу «подпись на экране → entity_id → текущее состояние»
   на подтверждение. Если доступа нет — попроси меня выгрузить список
   (Инструменты разработчика → Состояния). НИКОГДА не придумывай entity_id:
   если не нашёл — спроси. Помни: HA добавляет к id комнату устройства
   (number.<комната>_<устройство>_<имя>), точные id панели станут известны
   только после первой прошивки.

4. Внеси изменения в tools/gen_panel.py (списки LIGHTS, YARD, PRESETS,
   entity_id в блоках sensor/text_sensor, подписи), а не руками в
   готовый YAML. Если меняется число плиток — пересчитай сетку так, чтобы
   отступы остались 12 px, а нижний ряд заканчивался на y=388 (таб-бар
   начинается с 400). Для новых подписей проверь, что все символы есть в
   глифах шрифтов (кириллица — glyphsets, MDI-иконки — списки mdi_font).
   Сгенерируй firmware/panel-saray.yaml.

5. Проверь сборку: `esphome config firmware/panel-saray.yaml`, затем
   `esphome compile` (или хотя бы `--only-generate`). Ошибки исправляй
   в генераторе. Если можешь — собери SDL-превью (tools/make_sdl.py) и
   покажи мне скриншоты всех экранов до прошивки.

6. Подготовь сторону HA по home-assistant/: таймер, автоматизации гашения
   экрана, скрипт быстрого запуска музыки (адреса станций/плейлистов —
   через music_assistant.get_library), хелперы тренда. Если есть доступ к
   HA — создай их сам и покажи, что создал; если нет — дай готовый YAML
   с моими id.

7. Напомни мне:
   - включить у панели в HA «Allow the device to perform Home Assistant
     actions»;
   - заполнить secrets.yaml (по firmware/secrets.yaml.example);
   - первая прошивка — по USB, дальше по воздуху;
   - блок «ОБХОД БАГА ESPHome» (чёрный экран после OTA/Restart на
     ST7701S) не удалять, пока ESPHome не включит исправление PR #17646.

8. После первой прошивки: проверь логи HA на ошибки от панели, подставь
   реальные id сущностей панели в автоматизации и проверь вживую цепочку
   «движение → экран включился → таймер → экран погас».

Будь честным: если что-то не проверено на железе — так и скажи.
```

---

### Советы

* Хочешь поменять внешний вид — сначала попроси LLM нарисовать макет
  (HTML 480×480 по образцу `design/*.html`), согласуй его, и только потом
  переносить в генератор. Так дешевле переделывать.
* Просишь новую функцию — пусть LLM сначала проверит, нет ли готового пакета
  в библиотеке esphome-modular-lvgl-buttons.
