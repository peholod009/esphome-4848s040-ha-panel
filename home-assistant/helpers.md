# Хелперы HA

Все создаются в UI: **Настройки → Устройства и службы → Помощники → Создать помощника**.

## Таймер экрана (обязательно для гашения по движению)

* Тип: **Таймер**
* Имя: `Сарай экран 10 мин` → id `timer.sarai_ekran_10_min`
* Длительность: `00:10:00` (это запасное значение — реальную длительность
  автоматизации берут из настройки панели «Экран гаснет через»)

## Тренд температуры (для плашки «греется / остывает»)

### 1. Statistics — изменение за 2 минуты

* Тип: **Статистика (Statistics)**
* Источник: твой датчик температуры (у меня `sensor.troitskaya_banya_banya_temperature`)
* Характеристика: **change** (изменение)
* Макс. возраст: 2 минуты, размер выборки: 20, точность: 2
* Имя: `Баня темп. изменение (2 мин)`

### 2. Template sensor — направление

* Тип: **Шаблон → Сенсор**
* Имя: `Баня температура тренд` → id `sensor.bania_temperatura_trend`
* Шаблон состояния:

```jinja
{% set d = states('sensor.bania_troitskaya_banya_bania_temp_izmenenie_2_min') | float(0) %}
{% if d > 0.3 %}rising{% elif d < -0.3 %}falling{% else %}stable{% endif %}
```

Панель понимает ровно три значения: `rising` (греется), `falling` (остывает),
всё остальное — «стабильно».
