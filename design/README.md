# design/ — HTML-макеты экранов

Исходники дизайна: по одному HTML на экран, 480×480, всё в абсолютных
координатах в пикселях — один пиксель макета = один пиксель панели.
Из них сгенерирована прошивка (`tools/gen_panel.py`), так что координаты
и размеры в макете и в LVGL совпадают.

| Файл | Экран |
|---|---|
| [`index.html`](index.html) | все экраны на одной странице |
| [`main.html`](main.html) | Главная |
| [`light.html`](light.html) | Сарай (свет в помещении) |
| [`yard.html`](yard.html) | Двор (уличный свет) |
| [`music.html`](music.html) | Музыка |
| [`settings.html`](settings.html) | Настройки |

**Посмотреть:** скачай папку и открой `index.html` в браузере (вкладки внутри
макетов кликабельны). Шрифт Nunito грузится с Google Fonts — без интернета
будет системный.

## Как пользоваться, чтобы переделать под себя

1. Поменяй подписи, иконки, цвета или раскладку прямо в HTML (или попроси
   LLM — см. `docs/LLM_PROMPT.md`) и смотри результат в браузере.
2. Когда макет устраивает — перенеси изменения в `tools/gen_panel.py`
   (координаты, размеры, цвета, подписи) и сгенерируй прошивку.

Правила, по которым CSS переносится в LVGL (описаны в шапке
`tools/gen_panel.py`):

* **Клавиша** (всё, что нажимается, класс `.key`): обводка 2 px + нижняя
  «губа» 6 px. В LVGL губа — жёсткая тень `shadow_offset_y: 4`, а высота
  кнопки = высота в CSS − 4. При нажатии кнопка «вдавливается».
* **Показание** (класс `.card`): плоская светлая карточка без обводки и губы.
* **Текст**: в LVGL координата — верх строки; `y = top + (line-height − 1.364·font-size) / 2`.
* **Иконки** — Material Design Icons: в макете вставлены SVG-путями, в
  прошивке — шрифт MDI. Несколько значков нарисованы в макете вручную
  (баня, туалет, эквалайзер «играет»); в прошивке вместо них MDI
  `pot-steam`, `toilet`, `equalizer`.

## Палитра

| Роль | Цвет |
|---|---|
| Акцент (включено, слайдеры, пауза) | `#F37320`, губа `#C85A12` |
| Тёмный (активная вкладка, ручки слайдеров, вторичный текст) | `#606682` |
| Текст | `#212121` |
| Клавиша: подложка | градиент `#F7F7FB → #E8EBF4`, обводка `#C7CCDE`, губа `#A9AFC4` |
| Карточка-показание | `#F3F4F8` |
| Включённая плитка | `#FDECD9`, обводка `#F37320`, губа `#C85A12`, текст `#B4500E` |
| Плашка «Парная» | `#FDEEE3` |
| Занято / свободно | `#FCE4E4` + `#B3261E` / `#E3F4EA` + `#1B7A43` |

Значения в макетах (время, трек, температура, Wi-Fi, IP) — демонстрационные.
